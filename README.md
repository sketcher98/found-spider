# Found — The Curiosity Cabinet with a Web-Spinning Spider

A single-file, full-screen interactive home page for **found**, a personal archive of curious objects ("the curiosity cabinet").

Recreated from the MotionSites "Spider Web" prompt (found-spider). Plain electric blue with a giant white wordmark, floating collectible cut-outs (mug, glass radio, iBook, book+iPod, t-shirt), and a photo-real jumping spider that:

- drops in on a silk thread and walks on inverse-kinematics legs (alternating tetrapod gait),
- chases a fly that replaces the mouse cursor,
- spins real silk: sagging Verlet ropes with dew drops, fuzz, iridescence, and shadows that fall only on the objects,
- pounces when you click, wraps the fly in a silk cocoon,
- blinks when idle (cute face crossfade) and falls asleep with drifting "z"s,
- clears the web on Delete/Backspace (hold on touch).

All in one HTML file, single 2D canvas, zero libraries.

## Controls
- Move the mouse — the fly follows; the spider follows the fly
- Click / double-tap — spider pounces at the fly
- Delete / Backspace — shake the web off (hold 650ms on touch)
- Radio player — play/next/prev/shuffle (SomaFM streams)

## Run
Open index.html in any modern browser (or serve statically).
